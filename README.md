# Stadtklima-Labor

Eine kleine deutschsprachige Informationswebsite über **städtische Wärmeinseln**, ihre Ursachen und mögliche Maßnahmen für angenehmere Städte.

**Website:** https://dsongtn.github.io/stadtklima-labor/

## Themen

- [Wärmeinseln verstehen](https://dsongtn.github.io/stadtklima-labor/) – Bebauung, gespeicherte Wärme, Verdunstung, nächtliche Abkühlung.
- [Fünf Maßnahmen gegen Stadthitze](https://dsongtn.github.io/stadtklima-labor/massnahmen.html) – Bäume, Entsiegelung, Regenwasser, Begrünung und Oberflächen.
- [Quellen und wissenschaftliche Einordnung](https://dsongtn.github.io/stadtklima-labor/quellen.html) – Ursprungsquellen, Grenzen und Arbeitsweise.

## Über dieses Projekt

Das Stadtklima-Labor ist ein **fiktives, nicht kommerzielles Informationsprojekt** und keine Forschungseinrichtung. Aussagen zu Stadtklima und Klimaanpassung stützen sich auf öffentlich zugängliche Publikationen des Deutschen Wetterdienstes und des Umweltbundesamts. Die Website veröffentlicht keine eigenen Messungen und gibt keine standortspezifischen Gutachten aus.

## Technik

Statische Webseiten aus HTML und CSS, einschließlich einer schematischen SVG-Illustration. Keine Benutzerkonten, Cookies, Werbung, externen Schriftarten oder Tracking-Skripte. Bereitstellung über GitHub Pages.

Die Inhalte dürfen für Lernzwecke gelesen und überprüft werden. Bei fachlichen Fragen sind die im jeweiligen Text verlinkten Originalquellen maßgeblich.
