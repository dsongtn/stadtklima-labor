# Stadtklima-Labor

Deutschsprachige, nichtkommerzielle Informationsseite zu städtischen Wärmeinseln und Hitzeanpassung.

Website: https://dsongtn.github.io/stadtklima-labor/

Das Projekt beruht auf der bestehenden **Start Bootstrap Clean Blog** Vorlage. Die Dateien `css/styles.css` und `js/scripts.js` entsprechen der übernommenen Vorlage; die inhaltliche Anpassung und kleine Gestaltungsergänzungen sind projektspezifisch. Die Vorlage steht unter der MIT-Lizenz (siehe `TEMPLATE-LICENSE.txt`).

Fachliche Quellen: Deutscher Wetterdienst, Umweltbundesamt, NASA Earth Observatory und US EPA. Die Seite behauptet keine eigenen Messwerte und keine Zugehörigkeit zu diesen Einrichtungen.
